# Erforderliche Software für lokale Entwicklung

## Docker

Installieren Sie entweder [Docker Engine](https://docs.docker.com/engine/install/) (Linux) oder
[Docker Desktop](https://docs.docker.com/desktop/) (Mac, Windows, Linux).

## Python

Installieren Sie [Python](https://www.python.org/downloads/) 3.13. Für Mac oder Linux empfehlen wir die Verwendung von
[pyenv](https://github.com/pyenv/pyenv).

## Node.js®

Installieren Sie [Node.js®](https://nodejs.org/) 22. Für Mac oder Linux empfehlen wir die Verwendung von
[nvm](https://github.com/nvm-sh/nvm). Für Windows empfehlen wir die Verwendung von
[nvm-windows](https://github.com/coreybutler/nvm-windows).
